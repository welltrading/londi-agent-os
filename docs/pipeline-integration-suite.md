# E4-T08 Pipeline Integration Suite

The internal integration suite exercises all MVP pipeline templates without UI:

- Direct
- Plan & Build
- Plan, Build & Review

## Covered gates and flows

- Gate A pipeline approval
- Gate B handoff approval when required
- Gate E acceptance snapshot
- Plan, Build & Review correction cycle
- Critical sensitive review stop

The suite is intentionally internal and deterministic so it can run in CLI/CI without browser or desktop dependencies.
