# E7-T04 Windows Notifications

Windows notifications are non-sensitive attention prompts only.

## Rules

- Notification action can open the local UI or dismiss the prompt.
- Notification cannot approve, reject, accept, retry, replace, stop, or auto-decide.
- Reminder is scheduled after 15 minutes.
- Reminder loop stops after 60 minutes.
- Closed UI does not stop or pause the run.
- Body text is redacted and capped before display.
